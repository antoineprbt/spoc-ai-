BLACKSITE / METHODOLOGY

From signal to review.

One local ML model, explicit correlation rules, and a score you can inspect.

01

Detect unusual readings

Isolation Forest fits 200 trees to 1,000 synthetic baseline rows (seed 42). It examines voltage, temperature, particles, and vibration. A negative decision value flags an anomaly. The 2% contamination setting defines a training threshold; it is not an accuracy claim.

02

Link relevant observations

Rules connect related event types within 120 seconds in the same zone, or the same event type in adjacent zones. NetworkX stores facility, zones, sources, observations, and links. Correlation does not demonstrate causation.

03

Explain the review priority

Priority = anomaly (up to 55) + independent corroboration (up to 25) + authored severity (up to 20) − contradiction (up to 20), bounded to 0–100. Repeated reports from one source count once. This is a review heuristic, not a probability.

What the application does not establish

Camera observations and field reports are authored scenario inputs. No computer vision or language model interprets them. No real-world accuracy, identity, intent, cause, or attack prediction is claimed. An analyst must verify every alert.
